# DevOps & Infrastructure Portfolio - Mohamed Ikbal Insaf Ahmedh

This repository contains sanitized samples of CI/CD pipelines and Infrastructure-as-Code configurations I have designed. These examples demonstrate my ability to automate the full software development lifecycle.

## 🚀 Key Highlights

- **Automated GitOps:** A Jenkins pipeline that builds Docker images and triggers automated deployments via ArgoCD.
- **Multi-Stack CI:** GitHub Actions workflows for Node.js, Java (Maven), and Python (Flask/Gunicorn).
- **Security & Quality:** Integrated SonarQube SAST and Quality Gate checks in every pipeline.
- **Container Orchestration:** Complex multi-service Docker Compose setups for local and production-like environments.

## 📁 Repository Structure
- `/jenkins`: Jenkinsfile for Python Middleware deployment via ArgoCD.
- `/github-actions`: Quality assurance workflows for Frontend (Node) and Backend (Java).
- `/docker`: Files related to docker.
- `/kubernetes`: Manifests for automated deployment.
